CHOIR SONGS BOOK — PWA PACKAGE

Included:
- index.html: the app interface
- choir-songs.pdf: your supplied songbook
- manifest.webmanifest: installable app details
- sw.js: offline cache
- icon.svg: app icon

IMPORTANT:
A PWA must be hosted on an HTTPS website for installation and offline caching to work.
This package is ready to upload; no programming edits are required.

FREE PUBLISHING OPTION (GitHub Pages):
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository named choir-songs-book.
3. Choose Add file > Upload files.
4. Extract this ZIP on your computer, then upload ALL files inside the folder (not the ZIP itself).
5. Commit the upload.
6. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
7. Wait for the Pages URL to appear.

Install:
- Android: open the HTTPS Pages URL in Chrome, then choose Install app / Add to Home screen.
- iPhone: open the URL in Safari, tap Share, then Add to Home Screen.

OFFLINE:
Open the app once while connected and allow the PDF to load completely. The service worker then caches the PDF for offline use. Keep the app hosted at the same URL for future updates.

LIMITATIONS:
- This is an installable web app (PWA), not a native APK/IPA.
- Apple App Store and Google Play publication are separate processes and may require developer accounts/fees.
- PDF viewing uses the device/browser PDF viewer. Some iPhone versions may open the PDF in a separate preview.
